# Bony Wings

Menú y pedidos por WhatsApp (PWA). Abrir `index.html` (o publicar la carpeta en GitHub Pages).

```
index.html            página mínima (solo contenedores)
manifest.webmanifest  datos de la PWA
sw.js                 service worker (modo offline)
css/main.css          estilos base
css/order.css         estilos del pedido (tipo de entrega, cantidades)
css/theme-dark.css    tema oscuro (colores y contraste)
js/config.js          número de WhatsApp, mínimo, redes, tipos de pedido
js/catalog.js         productos, precios y opciones
js/cart.js            carrito en memoria y mensaje de WhatsApp
js/templates.js       plantillas HTML
js/ui.js              interfaz y envío
js/privacy.js         borrado automático de datos del cliente
js/pwa.js             instalación de la app
js/main.js            arranque
img/menu/             imágenes del menú
img/brand/            logo e íconos
img/icons.svg         íconos (WhatsApp, Instagram, Facebook, TikTok)
```
